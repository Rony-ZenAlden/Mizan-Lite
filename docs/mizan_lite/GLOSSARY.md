# Mizan Lite — glossary (المصطلحات)

One term for one thing, in both languages (L8 D-L8.8). The screens, the printouts, the guides and this register use these words
and no synonyms; the navigation gate holds the screen names apart.

| English | العربية | What it means |
|---|---|---|
| Till | الصندوق | The selling screen: scan, price, take the money |
| Cash drawer | حركة الصندوق | What should be in the drawer, the counts and the cash book |
| Sale / receipt | فاتورة | One sale, with its number, lines, total and what was paid |
| Voucher | سند | The paper a debt payment or refund prints, with its own number |
| Void | إلغاء | Cancelling a whole sale, with the owner's PIN and a reason |
| Credit sale | بيع بالآجل | A sale whose balance becomes a customer's debt |
| Payment | دفعة | Money a customer pays against a debt |
| Write-off | إعفاء | A debt the owner decides not to collect |
| Refund | ردّ مال | Money given back to a customer who is in credit |
| Reversal | عكس قيد | Undoing a debt entry or a cash entry, on the day it is undone |
| Opening balance | دين سابق | A debt carried in from the paper book |
| Opening stock | مخزون افتتاحي | The stock a shop had when it started using Mizan Lite |
| Delivery / receive | استلام بضاعة | Stock coming in, with its cost |
| Count | جرد / عدّ | What is actually there — of stock, or of the drawer |
| Average cost | متوسط الكلفة | The weighted average cost of one unit |
| Owner mode | وضع المالك | The two minutes after the PIN, when the owner's actions are allowed |
| Owner PIN | رمز المالك | The 6–12 digits that protect the owner's actions |
| Recovery code | رمز الاسترجاع | The code that recovers a forgotten PIN; shown once |
| Exchange rate | سعر الصرف | Pounds per one dollar, as the shop sets it |
| Backup | نسخة احتياطية | A verified copy of the whole shop at a moment |
| Outside folder | المجلد الخارجي | Where each backup is copied — a USB drive or a synced folder |
| Restore | استعادة | Putting a backup back, after saying what will be lost |
| Support file | ملف الدعم | The zip of logs and state the owner hands to whoever helps |
| Export | تصدير | A report as an Excel workbook or an A4 PDF |

**Figures.** Latin digits everywhere (0–9). Dates are `15/09/2026`, times `15:15`. Money is the figure then its currency's short
name (`15,000 ل.س`, `3.25 دولار`), never the two currencies added together.
