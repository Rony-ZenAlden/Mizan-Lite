# بطاقة الصندوق — ميزان لايت

اطبع هذه الصفحة واتركها بجانب الجهاز.

## المفاتيح

| المفتاح | العمل |
|---|---|
| Enter | إضافة الصنف بعد المسح، أو الدفع إذا كان الحقل فارغاً |
| F9 | ادفع |
| F4 | نقداً أو بالآجل |
| F2 | كمية آخر سطر |
| + و − | زيادة أو إنقاص آخر سطر |
| Esc | إغلاق نتائج البحث أو النافذة |

## البيع في ثلاث خطوات

1. امسح الباركود أو اضغط زر الصنف.
2. اكتب المبلغ المدفوع إن كان أكبر من المجموع.
3. F9 للدفع. الفاتورة تظهر وتُطبع.

## بالآجل

F4 ← اختر الزبون ← ادفع. الفاتورة تُطبع تلقائياً وفيها الرصيد وسطر التوقيع.

## آخر اليوم

1. حركة الصندوق ← **عُدّ الصندوق** لكل عملة.
2. تأكد أن ذاكرة USB موصولة إن كنت تستعملها للنسخ الاحتياطية.
3. أغلق البرنامج من زر الإغلاق — يأخذ نسخة احتياطية عند الإغلاق.

## يحتاج رمز المالك

الحسم · إلغاء فاتورة · تغيير سعر الصرف · تغيير سعر منتج · التقارير · المصاريف والسحب والإيداع · استعادة نسخة احتياطية · استيراد المنتجات.

## إن حدث خطأ

البيع مسجّل حتى لو لم تُطبع الفاتورة. للمساعدة: حول التطبيق ← احفظ ملف الدعم.
